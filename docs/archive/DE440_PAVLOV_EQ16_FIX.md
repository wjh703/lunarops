# 动态月球二阶场：Pavlov 式 (16)

2026-10-12 按用户确认的模型方案，将独立静态偏置接入正式二阶场计算。

全月机械惯量仍为未形变对角惯量加潮汐／离心形变；只在生成引力场时使用
Pavlov et al. (2016) 式 (16)：

```
C21 = C21_static - I13 / (M R²)
S21 = S21_static - I23 / (M R²)
S22 = S22_static - I12 / (2 M R²)
```

惯量在代码中已除以全月 `M R²`。J2 与 C22 的惯量映射不变。
输入静态系数是未归一化值；转换为完全归一化时，C21/S21 乘 `√(3/5)`，
S22 乘 `√(12/5)`。转换集中在 `inertia.py` 的一个公共计算函数中。

| 静态偏置 | DE430 | DE440 |
|---|---:|---:|
| C21 | 0 | 2.2779569194479859e-10 |
| S21 | 0 | 1.3343450358392620e-9 |
| S22 | 0 | 0 |

积分姿态使用 `lunarRotation.deformation` 下的 `c21Static`、`s21Static`、
`s22Static`；规定 BPC 姿态使用 `lunarDegree2Gravity` 下的 `c21_static`、
`s21_static`、`s22_static`。均默认零，DE440 配置显式写入上述常数，
不根据文件名或历表版本自动猜测参数。

积分姿态路径每次以“惯量映射 + 静态偏置”替换 Moon 的二阶场，所有轨道
非球形力和 figure 力矩继续共用这一个场。规定姿态路径使用“完整动态二阶场
减去静态输入场”的修正，所以即使 GFC 已含静态偏置，也不会重复计入。
未形变惯量、流核惯量、核幔耦合、初始姿态和角速度都不因偏置改变。

诊断脚本 `run_de440_degree2_probe.py` 改为设置正式配置参数，删除额外加场的
派生类，避免配置已有偏置后再加一次。历史作业的原 adapter 副本保存在原结果
目录中，旧输出和归档包保持其运行时含义。
