# DE440 地球引力极轴与 IAU 2006/2000A CIP 对比实验

日期：2026-10-12。目标是检验更换地球极轴是否改善剩余约 3.9 cm 的月球姿态残差。
所有实验保留原初值、潮汐／核幔参数、C21/S21 修正、GMSDOT、KBO 环及原力模型；
没有进入 LLR、参数估计或变分方程。两组积分重新运行，并保留完整对照。

## 新增 IAU 模型与轴定义

独立模块：`classes/dynamics/earth_iau2006_orientation.py`，不是对原 DE440 函数的覆盖。
程序新增 `earthPoleModel`：`ephemeris`（默认按原 `earthDynamicsFrame` 选 DE430/440）、
`de430`、`de440`、`iau2006_2000a`。实验固定 `earthDynamicsFrame: de440`，
仅 A 的 `earthPoleModel: de440` 与 B 的 `iau2006_2000a` 不同。

1. 用已有 `TimeScaleConverter.tdb2tt`，即 ERFA 的地心 `dtdb`（Fairhead–Bretagnon）
   转换到 TT；使用两部分 JD，不经过 UTC、闰秒或 EOP。
2. `erfa.pnm06a(TT)` 提供 **GCRS→date 真赤道／春分点**矩阵。
   `matrix[2,:] = matrix.T @ [0,0,1]` 为 GCRS 轴下的 CIP 单位矢量。
3. 用 `xys06a` 的 X/Y 和 `sqrt(1−X²−Y²)` 交叉核对，也用 ERFA 官方 C 测试向量
   核对。`pnm06a` 已包含 IAU frame bias，**没有再次施加 JPL ROTEX/ROTEY**。
4. 从极向量建立与 DE440 相同零经度约定的引力轴基底。没有使用 IAU date 春分点
   的经度替换现有引力坐标零经度，因此不会混入任意绕极轴的经度变化。

本实验比较的是 **ICRF 对齐的 GCRS／BCRS 坐标轴中的方向**。GCRS 是地心相对论
坐标系，BCRS 是太阳系质心坐标系；它们有不同原点和坐标定义，这里没有把两者
当作同一套位置坐标，也没有增加与实验无关的完整 BCRS/GCRS 事件转换。

CIP 是按约定划分天极运动和极移的中间极；它不等于角速度向量定义的瞬时自转轴，
也不能自动认定为实际地固重力场对称轴。DE440 采用的是历表积分中特定的简化引力极轴。
B 有意使用模型 CIP 作为该对称轴的替代假设。**没有 xp/yp、dX/dY、UT1 或其他未提供的 EOP**，
也没有将结果包装成完整 ITRS 地球姿态。

## 极轴实验设计与统计定义

每日 TDB 网格从 1969-01-01 到 2030-12-31，共 22645 个历元。
CSV 保存两模型 X/Y/Z 单位矢量、分量差（mas）、夹角（mas）和去趋势残差。
夹角采用 `atan2(|a×b|, a·b)`，避免小角度 acos 的精度损失。

对三分量矢量分别拟合截距／线性趋势；RMS 指矢量范数 RMS，不是单分量 RMS。
“平均偏差”同时给出有符号平均分量和平均夹角，不能把两者混为一谈。
周期分析包括线性趋势与固定周期正弦／余弦的联合最小二乘诊断，以及去趋势序列
的 Hann 窗 FFT；振幅 RSS 是各轴正弦／余弦系数的平方和开方，不等于矢量最大幅值。

进一步构造可精确相加的诊断差向量：单项→完整 IAU1980 章动→TT 自变量→
IAU2000A／IAU2006 对应章动及平黄赤交角，再替换岁差和偏置。
移除 JPL bias、加入 IAU bias 的两段变化合并为 `frame_bias_net`。
这些混合中间模型只作归因诊断，不是生产动力学模型；分解依赖操作顺序，
各项相关，**RMS 不可直接相加**。

## 固定状态的加速度／力矩隔离实验

同一每日网格查询 DE440 BSP 的 Earth/Moon 状态与 BPC 的月球 PA 姿态。
月球惯量由同一延迟时刻的 DE440 BPC 角速度与地月状态计算潮汐／离心变形，
A/B 共用完全相同的 K；惯量时间导数不进入这个静态力矩比较。
两组只改地球极轴，不传播、不重新拟合任何量。

分别构造 J2、J3、J4、J5 单独的场，保留现有 J2EDOT/J2ET2；
调用生产球谐内核，与独立 Legendre 多项式引力势解析梯度对照。
加速度是非球形项对月球的直接加速度，不含点质量项或地球反作用的重复添加。
形状耦合力矩调用 `EarthFigureTorque`，独立参考从地球 J2 的引力梯度 H 与
二阶质量矩 `Q=(tr(K)/2)I−K` 求 `ε_ijk (QH)_jk`，没有照抄生产叉积公式。

力矩单位为 `N/(M_moon R_moon²)`，即 s⁻²，不是未经归一化的 N·m。
同时保存惯性轴与同一 DE440 BPC PA 轴下的向量，避免把不同参考轴的分量直接相减。

补充隔离地球潮汐轴的影响：所有延迟状态、Love 数、时间滞后、太阳 GM 变化保持相同，
只替换当前地球极轴。这个效应也会出现在完整 A/B 积分里，因此应明确记录。

### 结论与问题分类

- **代码错误**：本次未发现原 DE440 极轴的符号、顺序、框架偏置或时间尺度实现错误。独立极轴／加速度／力矩验证和 A 组逐值复现均通过。
- **不同模型自身的差异**：完整 IAU 模型主要增加 DE440 特意截去的章动项；这些不同的周期驱动力改变了月球轨道及耦合姿态。B 是保留 DE440 外部历表与其他参数的月球局部替代模型，并非重新构建、重新拟合后的完整 IAU 行星历表。
- **参数重新拟合可能吸收的差异**：部分慢变偏差、初始自由响应可能被初值或模型参数部分吸收，但本实验没有检验这种可能性，更没有改动相关参数；不能声称重新拟合会消除所有周期差异。
- **默认配置建议**：继续使用现有 DE440 极轴；IAU 选项保留用于敏感性实验。B 对姿态的改善很小、残差主体不变，却明显恶化轨道的 DE440 复现。不能以这点姿态残差降低为依据覆盖原 DE440 模型。
