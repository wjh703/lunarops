# DE440 自转模型与原始资料逐项对照

日期：2026-10-14。检查用户提供的 Park et al. (2021) 原文及 DE440 技术注释，
对照当前 `lunarops_orbit_rotation_de440_environment_10a.yml` 和已完成的
2700 s、5400 s 十年联合积分。本轮新增诊断和报告，生产动力学与配置未改动。

**主要常数和论文式 (43)–(58) 的实现没有发现确定错误。仍存在二阶场约定和
平均运动率数值来源需要确认；现有证据不足以把其中某一项认定为 39 mm 的根因。**

## 残差和排查方向

重新读取这次两个作业的原始四元数，转为 ICRF 小转角向量后比较：

| 指标 | 当前结果 |
|---|---:|
| 2700 s 姿态最大月面尺度 | 39.087096 mm |
| 5400 s 姿态最大月面尺度 | 39.086719 mm |
| 两条姿态解的直接最大差 | 8.927973 µm |
| 2700 s 残差的 ICRF 线性漂移模长 | 4.701552 mm/yr |
| 去掉线性趋势后的三维 RMS | 6.919069 mm |

这里的尺度是 `1738000 m × 姿态夹角`，不等于 LLR 测距残差。
步长改变的姿态响应远小于现有残差，支持优先核查模型／参数约定。
这两档步长不构成完整的积分器收敛证明。

以前的受控十年实验已经检验了固定 BSP 轨道、Earth figure 力矩中的静态交叉项、
参考负时间种子：两解变化分别只有 9.266、4.601、0.393 µm。
更换为 IAU2006 地球极轴也只产生约 68.6 µm 的变化。
这些结果见 [剩余残差审计](DE440_REMAINING_ROTATION_RESIDUAL_AUDIT.md) 和
[地球极轴对照](DE440_IAU2006_EARTH_POLE_EXPERIMENT.md)，本轮没有重复提交这些长弧作业。

## 确认存在的约定差异和未明确的常数

### 1. C21/S21：当前保留独立静态引力偏置

Park 式 (32)–(34) 直接将二阶场系数写为总惯量交叉项的函数。
当前实现另保留 Pavlov 式 (16) 的独立静态项：

```
C21(t) = C21_static − I13(t)/(M R²)
S21(t) = S21_static − I23(t)/(M R²)
```

两个偏置分别为技术说明中的 `2.2779569194479859e-10` 和
`1.3343450358392620e-9`。机械惯量不另外添加这两个静态交叉项。
这确实是与 Park 打印公式的表述差异，并非遗漏常数。

已有十年试验：删除偏置得到 2.323 m；保留两项得到 39.087 mm；
在原轴系和原初值下把同样偏置简单加入机械惯量得到 6.125 m。
因此不能据此直接同步机械惯量。尚待确认的是 JPL 定版的 PA／重力场／
机械惯量约定，而不是常数的读取或归一化。
证据：[二阶场六组对照](DE440_ROTATION_CHAT_REVIEW_VERIFICATION.md)、
[已采用的实现约定](DE440_PAVLOV_EQ16_FIX.md)。

### 2. meanMotionRadS：这两份资料没有提供直接可核对的数值

当前离心形变使用 `n=2.6616995e-6 rad/s`，对应 27.32166128 day。
Park 式 (54) 指定 n 是平均运动率，但本次提供的正文和技术注释没有列出
这个常数的具体数值／计算约定，所以不能宣布这一项已经完全对齐 JPL。

以前本地 Julia DE430 实现由 GM 和 384399.014 km 的 Kepler 关系得到
约 `2.66532463e-6 rad/s`。这只是另一实现的候选约定，不能当成 DE440 真值。
本轮同状态局部 RHS 探针改为该 Kepler 值，地幔角加速度最大变化约
`1.215e-21 rad/s²`。还没有进行这项替换的 DE440 十年联合积分，不能给出
它能降低多少姿态残差的结论，也没有把候选值写回配置。

### 3. C22M：静态列表与惯量推导值存在小差别

技术说明：`C22M=2.2380845245752079e-5`。
按式 (47)–(49) 计算的惯量满足：

```
(B_T−A_T)/(4 M R²) = 2.2380850528178065e-5
差值                = 5.282425985888607e-12
```

当前生产模型在形变评价时按式 (31) 重新生成 C22(t)，并替换 GFC 的二阶场；
它没有把表中的静态 C22M 额外叠加一次。这与论文“二阶系数由时间变化惯量
计算”的描述相符。静态列表里的值与未形变推导值略有差别本身不证明代码错误。
作为独立局部探针，只在动态场额外加上上述小差值，最大角加速度变化约
`1.594e-22 rad/s²`。是否代表应有的 JPL 偏置，仍缺少物理依据。

### 4. JPL 完整积分与当前规定外部轨道的结构不同

论文描述同时积分太阳系轨道及月球自转；当前模型只积分月地相对轨道与
月球地幔／液核，其他天体轨道来自发布的 BSP。当前负时间形变历史也由
刚性反向种子生成，不是 JPL 原始积分历史。这些是实际结构差异。
已有固定 BSP 轨道和参考种子对照分别只影响 9.266、0.393 µm，
本场景下不支持把它们当成 39 mm 的主要解释。

## 本轮新增：规定 BPC 地幔下的液核传播和力矩闭合

直接规定 BSP 平动、BPC 姿态／角速度／解析二阶率，按同一式 (45)/(58)
从原 OMGC 初值传播三个液核角速度，再评价式 (43) 左右两侧的差。
这避免用原联合积分的液核状态冒充参考液核，仍然只是**给定模型下的液核解**，
因为 BPC 没有发布 JPL 液核历史。

115 个历元覆盖十年，均选在 8 天 BPC 段内固定相位，另保留初始历元探针。
局部角加速度闭合最大约 `3.297e-18 rad/s²`。但三段各取 64 点的独立检查发现：

| BPC 段起点（TDB s，自初始历元） | 段内闭合峰值 rad/s² | 全段平均向量模长 rad/s² |
|---:|---:|---:|
| 0 | 3.239e-18 | 4.421e-22 |
| 157593600 | 8.329e-20 | 1.991e-22 |
| 314496000 | 2.386e-19 | 2.015e-23 |

32／64 点积分的平均结果差约 `2.3e-27–3.9e-27 rad/s²`。
液核最大步长由两天降为一天，同时收紧容差，115 个采样时刻的最大核角速度
解差 `4.852e-15 rad/s`。

这说明局部二阶导数闭合中的大幅波动会在整段平均中显著抵消。
结合此前确认的 8 天多项式拼接及二阶导数跳变，**推断**参考多项式求导误差
可能占据局部闭合的重要份额；不能把每个 `1e-18` 的差直接解释为缺失物理力矩。
本轮没有证明全部波动来自 BPC 插值，也没有证明平均残差就是 39 mm 的根因。
三段覆盖不足以给出全十年的力矩偏差预算。

下一步应核实 n 的定版来源、二阶场约定，并用按 BPC 记录积分的角动量闭合
继续隔离平均残差；若实施候选长弧对照，应保持原初值、逐项改变并报告两解差。
不能用局部 RHS 差直接推算十年姿态改善，也不能靠拟合初始状态宣布修复。
