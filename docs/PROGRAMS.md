# Programs

LunarOps intentionally exposes three programs:

| Program | Purpose |
|---|---|
| `NormalPointsConvert` | Convert external MINI or CRD/FRD data to the canonical normal-point file. |
| `LlrResiduals` | Evaluate O-C residuals without estimating parameters. |
| `LlrProcessing` | Run nonlinear estimation and write the requested final products. |

```bash
python -m lunarops list-programs
python -m lunarops describe-program LlrProcessing
python -m lunarops validate config.yml
python -m lunarops run config.yml
python -m lunarops run config.yml --mpi
```

`--set name=value` overrides entries in `variables`. Validation checks the
schema, artifact graph, paths, and class choices without evaluating the LLR
model.

## Residual workflow

```yaml
programs:
  - program: NormalPointsConvert
    inputFilesNormalPoints: [data/input.crd]
    outputFileNormalPoints: output/normalPoints.txt.gz
    outputFileImportReport: output/importReport.txt.gz

  - program: LlrResiduals
    inputFilesNormalPoints: [output/normalPoints.txt.gz]
    outputLevel: standard
    outputFileObservationResults: output/oc.txt.gz
```

## Processing workflow

`LlrProcessing` keeps estimation stages and output selection in one ordered
`processingSteps` list. Selection and estimate steps must precede output
steps. Exactly one leading `screenObservations`, at least one `estimate`, and
at least one output step are required.

```yaml
programs:
  - program: LlrProcessing
    inputFilesNormalPoints: [output/normalPoints.txt.gz]
    varianceComponents:
      - {id: all, station: STA, start: 2000-01-01, endExclusive: null}
    processingSteps:
      - type: screenObservations
        residual:
          maximumAbsoluteM: 2.0
        reportedSigma:
          minimumOneWayM: 1.0e-3
          minimumFractionOfGroupMedian: 0.1
      - type: selectParametrizations
        parametrizations: [reflectorPosition, stationRangeBias]
      - type: estimate
        name: joint
        maxIterationCount: 10
        estimateVarianceFactors: true
        estimateRobustWeights: true
        robustWeighting: {model: igg3, k0: 1.5, k1: 6.0}
      - type: writeResiduals
        outputFile: output/postfit.txt.gz
        outputLevel: full
      - type: writeNormalEquations
        outputFile: output/normals
      - type: writeResults
        outputFileReport: output/processingReport.txt
        outputFileState: output/processingState.txt
        outputFileSolution: output/solution.txt
        outputFileCovariance: output/covariance
        outputFileReflectorCatalog: output/reflectors.txt
```

The full accepted model and estimation fields are generated by
`describe-program`; the registry is authoritative.
