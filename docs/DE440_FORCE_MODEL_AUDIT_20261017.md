## 确认存在的差别与尚未确认的约定

1. **主要天体 GM 的截断差别。** 水星、火星质量表采用技术注释较短的 km³/s² 列，
   相比完整 AU³/day² 常数换算，分别差 −400.008、+243.891 m³/s²，
   相对差 −1.82e-11、+5.69e-12。其他大天体至多约一个浮点末位；373 个小天体不改。
   这是有官方完整数值支持的精度差别，是否影响 39 mm 必须由长弧验证。
2. **离心形变的 n。** 当前为 2.6616995e-6 rad/s，对应恒星月约 27.32166128 day。
   Park 文中只定义为 lunar mean motion，技术注释未列具体值。
   本地独立 DE430 Julia 实现由 GM 和 384399.014 km 半长轴计算
   2.6653246342740375e-6 rad/s。本轮只将其作为候选，不称为官方 DE440 数值。
   固定 undistorted 惯量的情况下改变 n，会改变常量形变张量，因此不能任意更换。
3. **C22 表值与惯量推导值。** C22M=2.2380845245752079e-5；
   (B_T−A_T)/4=2.2380850528178065e-5，表值减推导值为 −5.282425985888607e-12。
   当前动态二阶场按式 (31) 由惯量生成，符合论文描述。
   给引力场额外加此差值、同时保持机械惯量不变，是实验假设，并非论文要求。
4. **C21/S21 静态偏置。** 当前采用 Pavlov 式 (16) 的独立静态偏置，
   而 Park 式 (32)/(33) 的打印形式仅写惯量交叉项；机械惯量保持 undistorted 对角形式。
   这是真实的表述／约定差别，不能宣布完全复现 JPL 内部二阶约定。
   已有受控实验删除偏置后为 2.323 m，加入偏置为 39.087 mm；
   直接把相同偏置加入机械惯量、沿用原轴和原初值则为 6.125 m。
   因而本轮保留已验证设置，未机械地“同步”两种张量。
5. **系统积分结构。** JPL 同时积分太阳系天体；本项目规定 Earth/其他天体 BSP，
   积分月地相对轨道和月球自转，负时间形变历史由刚性种子提供。
   相对加速度是模型 Moon 绝对加速度减 BSP Earth 加速度；
   潮汐先按质量比还原 Moon 份额，避免重复计入 Earth 的反作用。

## 2026-10-18：C22 恒等式与偏置依据复核

用户指出，同一惯量张量对应的 C22 理论上应完全一致。这一点成立。
Park 式 (31)、(47)–(51) 给出的未形变关系为

```text
C22_und = (B_T − A_T) / (4 M R²)
        = J2_und * gamma * (1 + beta) / [2 * (2*beta − gamma + beta*gamma)]
```

后三个输入一旦确定，C22_und 就是派生量，不能再作为独立约束自由指定。
这也意味着，只在引力场加偏置而不改机械惯量，不再满足原式 (31)。

本次从 `de440.bsp` 内嵌注释直接读取 J2M、LBET、LGAM 和 C22M，
四个数的全部公开位数均与 `de440_tech-comments.txt` 相同。
用 80 位 Decimal 直接计算上述闭式关系，避免两个接近的惯量相减：

| 项目 | 未归一化数值 |
|---|---:|
| BSP 注释中的 C22M | 2.2380845245752079e-5 |
| J2M/LBET/LGAM 推导的 C22_und | 2.2380850528171017118e-5 |
| 表值减推导值 | −5.282418938118109e-12 |
| 相对差 | −2.36024047945e-7 |

生产 double 的惯量相减给出 `2.2380850528178065e-5`，
它与高精度推导值的差约 `7.05e-18`；这解释了之前偏置末几位的变化，
不能解释约 `5.28e-12` 的主要差异。
即使四个公开常数各允许半个末位的舍入变化，总影响也仅约 `1.87e-21`。
因此差异不是本项目抄录、double 相减舍入或公开位数截断造成的。
当前 GFC 的归一化 C22 与 C22M 乘 sqrt(12/5) 只差约 `2.33e-21`，
常见的 fully normalized / unnormalized 换算也不是来源。

不能直接用“平均值与未形变值定义不同”解释本次差值：论文确实说明潮汐存在
非零平均，但没有说明技术注释中的 C22M 就是这个平均值。
本次独立采用 BSP 位置、BPC 姿态及解析角速度，在原十年输出网格的
3654 个延迟历元上用式 (54) 的分量公式计算，得到：

- 潮汐 C22 修正范围约 `+3.79e-8` 至 `+5.67e-8`，样本均值 `+4.47801958e-8`。
- 旋转 C22 修正均值约 `−4.64e-15`，远小于潮汐项。
- 总形变 C22 修正均值约 `+4.47801912e-8`，与原积分记录的总惯量结果一致。

这与表值减推导值的符号、量级都不同，不能用普通的潮汐平均修正直接对上。
离心形变中的 n² 对 xx、yy 的贡献完全相同，在 C22 差分中严格抵消，
也不能直接产生这两个未形变数值之间的差。

**已确认的是：若把技术注释的 C22M 解释为同一未形变惯量的 C22，
它与 J2M/LBET/LGAM 不满足理论恒等式。尚未确认的是 JPL 内部对该 C22M
的实际使用方式。** 现有原文没有交代它是独立参与计算的引力场输入、
冗余／旧的派生输出，还是另有参考定义；不能据此认定 JPL 的实际积分违反恒等式，
也不能选定某一种可能作为已查明的原因。

因此，上次加入偏置的作用应表述为“使本项目引力场的未形变 C22 基值对齐技术
注释中的 C22M 的受控实验”，不能表述为“已修复错误的惯量推导”。
39.087 mm 降至 34.000 mm 说明该扰动能减少残差，不能单独证明它就是
JPL 的正确实现。本次保留已授权的实验设置，没有修改物理参数或重新拟合。

只读复核脚本与全部中间数值分别为
[check_identity.py](../output/de440_c22_identity_20261018/check_identity.py)、
[identity_check.json](../output/de440_c22_identity_20261018/identity_check.json)。

## 2026-10-18：反向 J2 与 C20 路径核对

上一节以 J2 为输入推导 C22，已经检验了四个常数的联合关系，但没有独立证明
J2 就是正确的一项。按用户要求进一步固定官方 C22M、LBET、LGAM，反算

```text
J2_implied = 2*C22M*(2*beta − gamma + beta*gamma) / [gamma*(1 + beta)]
```

| 项目 | 未归一化数值 |
|---|---:|
| 官方 J2M | 2.0321436013500001e-4 |
| 官方 C22M、LBET、LGAM 所要求的 J2 | 2.0321431217152413032e-4 |
| 反算值减官方 J2M | −4.796347587968106e-11 |
| 相对差 | −2.36024047945e-7 |

这与正向 C22 检查是同一个不一致的反向表达，不能只凭反算就判定 J2 错了。
只给 J2 和 C22 本身也不能检验三轴惯量形状；这里的约束还使用了官方 beta、gamma。

同时核查了实际生产路径：

- 两个联合积分配置直接读取 `inertiaMoments`。这些实际 double 数用 Decimal
  反算 `J2 = C − (A+B)/2`，为 `2.0321436013495675077e-4`，
  与官方 J2M 差 `−4.33e-17`，并未暗中采用反算的较小 J2。
- 静态 GFC 的 `C20 = −9.0880224653200e-5`，按
  `J2 = −sqrt(5)*C20` 得 `2.0321436013500745e-4`，
  与官方 J2M 差 `+7.44e-18`。符号和 fully normalized 换算一致。
- 规定姿态模型以 `j2Undistorted` 构造未形变惯量；联合积分模型以配置惯量为基准。
  两条路径在评价形变时都从总惯量覆盖全部二阶系数，动态 C20 不是始终固定为静态文件值。
- 在原十年 3654 个实际总惯量张量上，生产映射生成的 J2 与直接分量公式
  的最大绝对差为 `8.57e-17`；C22 不加偏置时为 `1.73e-17`。
  加 C22 实验偏置对 C20 的改变严格为零。
- 独立 BSP/BPC 分量计算的总形变 J2 样本均值约 `+8.94682630e-8`，
  与原积分总惯量的 `+8.94682627e-8` 一致。它不是约 `−4.80e-11`
  的普通平均形变修正；未发现把含潮汐的 J2 当作未形变基值的代码路径。

本次重新逐段阅读还确认：Pavlov (2016) §5.1 明确说明其模型固定 GRAIL 的
未形变 J2，拟合 beta、gamma，并舍弃 GRAIL 的独立未形变 C22 输入，
让 C22 按式 (16) 动态生成。这说明同类模型不能把四个独立来源的数值同时
强制视为同一惯量张量的约束；但这份独立实现的说明，不能直接证明
DE440 注释中的 C22M 就来自某份 GRAIL 解，也没有直接解释其具体差值。

对固定状态，改变离心形变的 n 给出

```text
delta J2 = −k2*R³/(3*GM_M) * delta(n²)
delta C22 = 0
```

因此“n² 在 C22 中抵消”不能用于排除 n 经由 J2 和机械惯量影响长期误差。
既有 Kepler n 实验给出的 `delta J2 = −1.667356642e-10` 仍适用，
但没有据本次反算值调 n 或替换 J2。只读脚本与 JSON 已补齐上述反向检查。
